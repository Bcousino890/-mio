## 7. Animaciones Timeline

### Drawer Entrada
```
t=0ms:    Drawer off-screen (y: 100%)
          ├─ Opacity: 0
          └─ Overlay: rgba(0,0,0,0)

t=150ms:  Drawer 50% visible
          ├─ Opacity: 0.5
          └─ Overlay: rgba(0,0,0,0.25)

t=300ms:  Drawer fully visible ✓
          ├─ Opacity: 1
          └─ Overlay: rgba(0,0,0,0.5)

Animation: slideInFromBottom 0.3s cubic-bezier(0.16, 1, 0.3, 1)
```

### Grupo Expandible
```
t=0ms:    Collapsed (height: 0, opacity: 0)

t=100ms:  Mid-animation (height: 40%, opacity: 0.5)

t=200ms:  Expanded ✓ (height: auto, opacity: 1)

Animation: expandHeight 0.2s ease-out
```

### Range Slider Thumb

## 12. Responsive Transiciones

```
xs → sm (320px → 640px):
  Panel: drawer → drawer (sin cambio)
  
sm → md (640px → 768px):
  Panel: drawer → sidebar lateral
  Grid: 2 cols → 2 cols
  Animations: simplificadas
  
md → lg (768px → 1024px):
  Panel: sidebar ancho 320px → 360px
  Grid: 2 cols → 3 cols
  
lg → xl (1024px+):
  Panel: mantener 360px
  Grid: 3 cols (máximo)
```

## 14. Teclado & Accesibilidad

```
TAB:        Navega a siguiente control
SHIFT+TAB:  Navega a control anterior
SPACE:      Toggle checkbox/radio
ENTER:      Confirmar selección
ESC:        Cerrar drawer/dropdown
ARROW ↑↓:   Navegar options en selects
ARROW ←→:   Mover range slider
```
