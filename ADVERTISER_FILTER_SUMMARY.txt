================================================================================
NOTAS IMPORTANTES
================================================================================

1. COMPATIBILIDAD: El campo advertiserType antiguo se mantiene
   → No hay breaking changes
   → Migración gradual del código

2. PROGRESIVA: Funciona sin columnas BD futuras
   → Las opciones privadas están deshabilitadas pero visibles
   → Se habilitan automáticamente después de migración

3. ALMACENAMIENTO: Todos los filtros se guardan en localStorage
   → Persisten entre sesiones
   → Se limpian con botón "Limpiar"

4. URLS COMPARTIBLES: Los filtros generan URLs limpias
   → Ej: ?advertiser_mode=particular&only_particular=true
   → Se pueden compartir/bookmarkear

5. FLEXIBILIDAD: Componentes funcionan con cualquier lista de agencias
   → No requiere estructura específica de BD
   → Se adapta a múltiples esquemas
